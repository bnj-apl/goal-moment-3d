# MOMENT90 product experience

Video freeze frames, collectible 3D prototypes, match-reference clips and a parameter-driven shooting interaction.

This `gh-pages` branch is the product demo. The original project handoff remains on the repository main branch and Releases.

The models are digital prototypes; physical printing and NFC-tag writing have not been completed. No claim of commercial rights clearance is made for third-party match footage, game assets or player/club marks.
