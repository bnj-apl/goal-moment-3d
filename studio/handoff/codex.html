一、产品目标与最新决定
从比赛直播中捕捉一个精彩瞬间，生成立体球星卡或球场摆件；收藏者触碰 NFC 或扫码，打开同一瞬间的原片、3D 电影与可旋转的三维周边。以 3D 为基础，人物可信、动作有比赛紧张感、产品精美。
当前用户明确选择：先用现有梅西原片模拟直播；暂时没有 NFC 标签，先完成可写入链接与扫码入口。时长不再是首要限制，优先可信的进球与梅西独自举起双手欢呼，不要多人挤压式庆祝。沿用已有诺坎普草坪光影 V3 和 Moment90 V3 人物修订宣传片。先做好影片与定格换视角衍生；真实动态 4DGS 后续单独验证。

三、在自己的电脑运行，二选一
A. 直接取可编辑网页源码（公开，无需 API 密钥）
git clone --depth 1 --branch gh-pages https://github.com/bnj-apl/goal-moment-3d.git moment90
cd moment90
python3 studio/tools/serve.py --open
默认 http://127.0.0.1:8877/studio/ 。端口占用用 --port 0 --open。Windows 可将 python3 改为 python。浏览器需要 WebGL 2；不要用 file:// 直接打开应用。
测试：另开终端进入 moment90/studio，执行 npm test。使用 Node.js 22+；内置测试器和本地三维库无需 npm install。
在修改前创建自己的分支，例如 git switch -c teammate/your-task；不要向 gh-pages 直接推送未验收的改动。

B. 下载本次私有 Release 的 Moment90-Studio-20261119.zip
需要本人 GitHub 账号有私有团队仓库权限。验证 SHA256SUMS.txt 后解压，进入解压目录，再执行 python3 studio/tools/serve.py --open。包内有本轮完整网页、四个 GLB、三段 MP4、图片、依赖、测试和说明。这个 ZIP 足够运行最新网页演示，但不含全部 Blender 源工程与历史研究。
要改原始工程，再按私有仓库 README 获取 handoff-2026-11-17 大素材；assets/manifest.json 只管理该历史素材包，本轮补充包用 assets/studio-2026-11-19.json。不要以 GitHub 自动的 Source code ZIP 替代大素材分包。不能访问私有仓库时，先继续公开演示复现；需要源工程时再请仓库所有者安排权限，不索要账号密码。

四、当前已实际实现
1. 40 秒、25 fps 原片模拟直播；真实 seek 与 canvas 截帧，上一帧／下一帧控制。
2. 三种精修三维模板：挑射浮雕卡、独立举手欢呼摆件、后期球衣黑金典藏卡。当前截图与编号、二维码合成到纪念卡和三维铭牌。
3. 可旋转、缩放、正面、人物近景、背面、环视；诺坎普 V3 有内部、看台、草坪、鸟瞰机位。
4. 导出专属 GLB、PNG、绑定 JSON、二维码 SVG、NDEF 与打印标签；同一个链接能在另一浏览器恢复对应记录并回看原片。
5. 3D 电影使用既有 LibTV 进球与独立欢呼样片（9.208 秒）；产品片使用既有 V3 人物修订宣传片（27 秒）。本次没有重新花费生成额度。
已验证：实际截帧、导出 GLB 含绑定数据与铭牌、实际 PNG 二维码解码、NDEF 一致、独立浏览器恢复、公开 HTTPS 原片播放与欢呼三维加载、390px 窄屏布局、5 项契约测试。390px 布局验证不是手机真机验证。

五、核心文件与不可破坏的约定
studio/index.html / style.css：页面与响应式布局。
studio/app.js：实际视频截帧、卡面与铭牌、生成流程、恢复、导出与播放。
studio/contract.js：记录校验、编号、链接与 NDEF，优先读它及 tests/contract.test.mjs。
studio/viewer.js：GLB 加载、材质灯光、人物近景、球场机位、带铭牌导出。
studio/provenance.json：素材大小、SHA256、用途、球场优化与验证边界。
studio/tools/serve.py：仅监听本机，支持视频 Range，请勿改为作者电脑的绝对路径。

数据契约：SOURCE.id=messi2015-v1；25 fps；帧号 0..999。记录 {v:'1',p:'c'|'d'|'g',n:帧号,f:'g'|'s'}。canonical 为 v.p.n.f，token 为 canonical + '.' + SHA256(sourceId + ':' + canonical) 的前 6 字节十六进制。entry=qr/nfc/link 不参与产品 ID。
固定回归：{v:'1',p:'c',n:451,f:'g'}，18.04 秒，编号 M90-C451-FEE679CB0324；token=1.c.451.g.fee679cb0324。独立欢呼 d451 的 token=1.d.451.g.1f252e7e53b1。
该编号是确定性的作品配方编号，不是购买订单、唯一实体编号或所有权证书；校验码防链接误拷，不是鉴权签名。网页无账号和云端数据库，localStorage 只保存当前设备收藏架，恢复依靠完整链接。
原片回看从捕捉点前约 5 秒开始，可继续播放整个 40 秒原片。电影动作与原片不是逐帧同步。
二维码用 canvas 原生模块绘制；不要退回曾导致 Safari 图像解码问题的 SVG 转图片路径。
球场已把 88,030 个重复座椅转为 29 个实例批次，交付 48 节点、约 68 MB，保留原几何与位置，贴图最高 1024。不要恢复 88,049 节点的原始网页版而导致浏览器卡死。
GLB 导出保留米单位与绑定铭牌，展示归一化不应写回模型实际尺寸。模型与影片更新时保留旧版本，更新来源与 SHA256；若 source/配方语义改变，做版本迁移并保证旧链接可解释。
分享链接当前固定指向公开演示地址。本地改动不会自动发布，也不会让公开链接加载本机未发布模型；分支回归应手动在本地地址附上同一个 ?m=... 查询串，正式发布前明确新域名和兼容策略。

六、不要误报的边界
真实直播接入、任意帧自动视频转三维、动态 4DGS、实体生产编号、打印试制、手机真机 NFC 写入/触碰均未完成。当前模型是精修静态模板，截图与铭牌会跟随捕捉帧，人物动作不会自动重建。LibTV 电影是视频，不是可自由换视角的动态三维。诺坎普是场馆设计资产，不是 2015 年实测建筑；黑金款是后期球衣设计。已有视觉结果仍需用户质量认可。
不把 Aholo / Lux3D API 接入或历史试验写成该版本采用了真实重建。当前发布选用已有原生三维与 LibTV 成片；是否追加生成，由实际质量缺口决定。

七、接手后依次做
第一轮：读文件、运行网页和 5 项测试；在 18.04 秒捕捉、选择举手欢呼、生成、看人物近景/背面、切原片/电影/球场；导出 GLB/PNG/NDEF，验证专属链接跨浏览器恢复。给出实际结果、最影响观感的三个问题、对应文件位置；不要仅汇报“服务启动成功”。
随后优先：手机真机加载与扫码回归 → 一件可制造的结构副本与试打 → 有标签后 NFC 写入/触碰 → 真实直播接入和可追溯的持久记录。动作制作线保留主角身份，改善脚球接触、重心、防守反应与镜头；先做可信短镜头。真正 4DGS 单独立项验收，不阻塞主体验。
每次提交附变化原因、可播放/可打开结果、同机位前后对照、检查证据与剩余限制；与当前基线比，不用模型数量或技术名词代替质量。
